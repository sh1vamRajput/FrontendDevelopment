CSS Box Model Exploration

Understand how content, padding, border, and margin interact visually.

Default Box Model (content-box)

Content

In content-box, width and height apply only to the content. Padding, border, and margin add extra space beyond those dimensions.

Alternative Box Model (border-box)

Content

In border-box, width and height include content, padding, and border. It makes layouts easier to manage and is used by most frameworks.
