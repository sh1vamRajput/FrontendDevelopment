Responsive Design Principles

Fluid Layouts

Use relative units like %, em, and rem to allow layouts to adapt to screen width.

width: 80%;
max-width: 1200px;
margin: auto;

Flexible Media

Ensure images and videos resize within their parent container.

img {
  max-width: 100%;
  height: auto;
}

Breakpoints

Use media queries to adjust layout for different screen sizes.

@media (max-width: 700px) {
  .container {
    flex-direction: column;
  }
}
